# Distributed-Multi-Camera-Localization

Motivation:
Multi-view pedestrian detection focuses on detecting pedestrians and estimating their actual location within the area. A key challenge is to achieve accurate localization while minimizing communication bandwidth,
computation, and end-to-end latency.

Design Goals: 
- Develop a model for embedded system to localize the pedestrian using multi-view cameras

Deliverables: 
- Develop efficient models to satisfy latency and memory constraints
- Use dataset to train and evaluate the localization technique
